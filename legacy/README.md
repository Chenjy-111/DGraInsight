# Legacy material — not the current paper system

This directory contains retired implementations, pre-paper project notes and superseded external-model studies. It is preserved for provenance and is not loaded by the website, used by the current tests, or included in the Offline Evaluator release.

- `session_v2/`: retired audit/session implementation and artifacts.
- `external_model_studies/`: superseded AGCRN and MTGNN integration studies.
- `pre_paper_project_notes/`: project briefs and scripts written before the submitted paper became authoritative.
- `pre_paper_stemgnn/`: exploratory StemGNN screening notes and video-bundle remnants that conflict with the final paper status.

Do not use files in this directory to describe current features or paper results.
